# PACON OuO 圆屏预览器

直接用浏览器打开 `index.html`。预览器使用与固件一致的 466×466 坐标，默认参数同步自 `main/fluid_pendant.c`。

可调整眼距、眼睛高度和大小、嘴部位置与尺寸；支持表情切换、鼠标交互、待机动画、PNG 截图和 C 参数复制。

## 2026-08-28 触点录像校准（当前交互）

参考 `Screenrecorder-2026-08-28-20-56-48-672.mp4`（246.109 秒）。按触摸白点逐段核对，并非把交互录像当成待机动画播放。

- 额头含两眼之间偏上区域：按住保持一字眼＋ω嘴，取消旧的横拖生气/700ms 困倦切换；松手显示约 6 秒灰色脸颊开心脸。
- 单眼按压：对应浅斜弧闭眼＋折线嘴，按住超过 650ms 也不跳惊讶；松手保留约 700ms 折线嘴后恢复。
- 拉嘴松手：约 650ms 闭眼短横嘴，不把残留拖动位移带到默认笑脸；普通点嘴仍是亲吻。
- 三角族：朝上、圆弧侧边，宽度由水平位移控制，高度由纵向位移控制。修正固件把受限的“显示位置偏移”当作拉伸输入的问题；三角族使用真实触点向量，和预览器同一组尺寸参数及轻微跟随位置。其他拉伸族未重写。
- 去掉每个 pointermove 引发的全脸透明闪动；嘴拖动和额头抚摸期间不被快速折返误判为眩晕。第二个触点不接管当前手势。
- 如果此前正在播放待机，触摸暂停，反馈结束后自动恢复；手动选择表情则保持手动状态。仍只做单指，不恢复双指挤压。

`tests/check_ouo_touch_recording.ps1` 使用实际预览脚本、可控时钟和离线原生 Canvas 跑真实 pointerdown/move/up/cancel，覆盖长按、松手、定时器抢占、左右侧拉、半圆折返、三角宽高像素边界。`experiments/touch-recording/android-comparison.png` 左列为录像局部按现有锚点归一化，右列为上述手势测试绘图，**不是等时长逐帧或相同触点轨迹的像素一致性证明**；固件已编译，真机触感/帧率需烧录验证。

## 2026-08-28 待机录像参考

点击「播放待机动画」播放 `Screenrecorder-2026-08-28-00-34-48-277.mp4` 的 80.782 秒参考序列，结束后从头循环。保留上半圆眼微笑、圆眼、半睁眼、难过、猫嘴、灰色脸颊张嘴及期间的眼睑过渡和长停顿。它是这一次录像的顺序重放，不是对 Android app 随机状态机的推断。

仅从录像截取左眼、右眼、嘴三个局部窗口（眼部窗口包含灰色脸颊），缩到原有 30px 眼半径和现有圆屏锚点；不复制手机录屏边框、触摸指示、导航栏，也不改变静态表情按钮和拉嘴算法。16 级灰度游程编码共 856,644 字节，538 个去重帧、898 个时间事件。固件常驻解码缓冲 25,728 字节，优先使用 PSRAM，只有图像改变时解码与标记重绘。

- 预览器：按画布暂停待机，交互反馈结束后恢复；选择静态表情则停止待机；点击播放可从头对照录像。
- 固件：启用原有 AUTO 后，在无触摸、无交互表情和回弹时自动播放；触摸/表情反应优先，反应结束重新开始参考序列。关闭 AUTO 或分配失败时回到原静态脸。
- 数据：`idle-reference.js` 与 `main/ouo_idle_reference.h` 由同一生成脚本输出；现有 C 参数导出仅描述布局，不包含动画素材。
- 重生成：安装独立工具环境中的 PyAV 后，运行 `tools/build_ouo_idle_reference.py <录像路径>`。录像时间戳为准，不按固定帧率推算。生成脚本另依赖 NumPy、Pillow。
- 校验：`tests/check_ouo_idle_reference.ps1` 检查所有 RLE 帧长度、两端数据一致性、时间边界、循环、保持帧、触摸打断和停止按钮；原拉扯回归也继续运行。`experiments/idle-reference/preview-timeline.png` 是实际预览代码的离线绘图，非真机截图。

## 状态来源与筛选

- 默认按 `capture_1_611/idle` 的真实比例绘制：30px 左右的圆眼、226px 眼间距和较窄较深的 U 嘴；眨眼只把圆眼上缘裁掉，不再缩成细线。
- 开心、亲吻和闭眼平静使用待机/长按采集到的浅上弧闭眼；开心不再错误复用默认圆眼。温和微笑则是保持圆眼后的轻量 U 形安全候选。
- 惊讶、亲吻、挤压分别对照 `tap_left_eye`、`tap_mouth` 和 cheek hold 采样；挤压仍是为圆屏安全做的友好改编，不复刻螺旋眼/巨型实心嘴。
- 猫嘴、尖嘴和嘴侧拉来自 OuO 1.611 的 ADB 长按/拖动采样，是当前圆屏候选状态；嘴上拉与猫嘴高度重复，仅保留作几何研究。
- 亲吻使用厚双弧 `3` 嘴；嘴侧拉使用左侧填充 `3`、白色中心横梁和独立右弧，右弧与左侧保留采集中的小黑缝。
- 嘴从中心向任意方向拖动会按向量显示连续形变；惊讶/亲吻拖动使用独立的左/右/上/下边缘和曲线，不旋转轮廓，也不会在 45° 附近强制变成方形。嘴中央水平/竖直拖动共用拉伸族：纯向下拖动只增加竖胶囊高度，不会横向变宽；当拖动方向逐渐转向水平且幅度增大时，才连续变成参考图中的宽扁嘴，并固定反侧边缘、只向手指方向扩展；斜向方嘴是独立随机族，边缘保持屏幕对齐，只按实际向量改变宽高和单侧弧度，不会变成右下菱形。要触发左右“嘴侧拉”，从白色嘴左半区或右半区开始水平拖动即可；嘴部命中区域优先于隐藏菜单，显示录屏中的填充 `3`+独立右弧并按拖动方向镜像。
- 拉嘴参考形的专用锚点比普通情绪嘴低 20px，与 Android 截图中眼睛到嘴的垂直间距一致；普通待机、开心、惊讶和亲吻嘴位置不受影响。
- 四个参考帧的眼睛使用约 0.87 的垂直压缩比例，匹配截图里略扁、下缘平直的白色眼形；普通状态仍是正圆眼。
- 双眼压缩、拉伸 H、压左眼、压右眼和嘴上拉使用虚线紫字标记，仅用于研究连续手势形变，不代表独立情绪或正式固件状态。
- 当前真机触发映射以上方“触点录像校准”为准。旧的眼睛超时惊讶、头部横拖生气/长按困倦映射不符合新录像，已移除；对应静态预览按钮仍可查看。脸颊单指按压、非拉嘴时摇晃眩晕、隐藏菜单低情绪难过保留。
- 预览器与固件使用相同椭圆命中区和新反馈时序；眩晕的螺旋眼动画保留，但不抢占按住嘴的手势。
- 嘴部每次开始明显拖动时随机选择圆、拉伸、方嘴或尖角族，同一次拖动保持该族，只随距离改变大小；拉伸族只在横向/竖向之间按当前方向输出宽扁或胶囊，不会因为轮廓旋转而出现菱形。嘴侧拉是独立的边缘水平手势，不再被随机族吞掉；四个虚线研究按钮仍可固定查看对应参考帧，嘴侧拉按钮仍固定显示录屏的填充 `3`+独立右弧。

Android 采集库和限制记录见 `../../../_ouo_reference/capture_1_611/CAPTURE_NOTES.md`。
当前采集已覆盖单击、长按、单指拖动、待机动画和人工多点触控录屏。

桌面预览用于确定圆屏构图和几何关系，OLED 的实际亮度、像素响应及触摸手感仍需最后一次真机确认。
